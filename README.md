# My Portfolio

Here is my portfolio! A responsive frontend web application built using React and Tailwind CSS.

## Tech Stack

I built it using HTML, CSS, Javascript with the help of Node.js, React and TailwindCSS.

## Features
- Responsive design
- Smooth navigation
- Modern UI styling

## Demo
[https://username.github.io/my-website](https://williamli218.github.io/Portfolio/)

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
```bash
git clone https://github.com/williamli218/Portfolio.git
cd my-website
npm install
```

To run locally, 
```bash
npm run dev
```
